# Keyboard shortcuts

Mails works without a mouse. One-letter keys never fire while you type in a
field, or inside the composer, a menu or a dialog. Keys held with Ctrl,
Cmd or Alt are left to the browser, except the ones listed here.

## Anywhere

| Key | What it does |
| --- | --- |
| `Ctrl` + `K` (`Cmd` + `K` on a Mac) | Open the command menu |
| `c` | Write a new message (on the mail screen) |
| `/` | Search mail (on the mail screen) |

## The command menu

Type to find a folder, a mailbox or domain, a label, a settings page or the
docs, or an action: **Write message**, **Toggle theme**, **Collapse
sidebar**. Letters only have to come in order, so `strd` finds Starred and
`set dom` finds Settings → Domains. The last row, **Search mail for “…”**,
searches the list you are in (or the Inbox).

| Key | What it does |
| --- | --- |
| `↑` `↓` | Move through the results |
| `Enter` | Open or run the highlighted one |
| `Esc` | Close |

## In the list

Press `Tab` to reach the list; it is one stop, and the keys below move
inside it.

| Key | What it does |
| --- | --- |
| `↓` or `j` | Next email (side by side, it also opens) |
| `↑` or `k` | Previous email |
| `Home` / `End` | First / last email |
| `Enter` | Open the email |
| `x` | Select or unselect it |
| `e` | Archive |
| `s` | Star or unstar |
| `u` | Mark read or unread |
| `b` | Snooze (pick when it comes back) |
| `#`, `Delete` or `Backspace` | Move to Trash (in Trash: delete for good, after asking) |

With emails selected, `e`, `s`, `u`, `b` and Delete act on all of them.

## In an open conversation

These work while focus is anywhere in the conversation, the mail itself
included, or nowhere in particular.

| Key | What it does |
| --- | --- |
| `r` | Reply |
| `a` | Reply all |
| `f` | Forward |
| `j` / `k` | Next / previous conversation in the list |
| `Esc` | Back to the list (side by side: focus goes back to its row) |
| `e` | Archive |
| `#`, `Delete` or `Backspace` | Move to Trash (in Trash: delete for good, after asking) |
| `s` | Star or unstar |
| `u` | Mark unread and go back to the list |
| `b` | Snooze (pick when it comes back) |

Reply, reply all and forward answer the last message, like the buttons at
the end of the conversation. They do nothing while another message is
open in the composer.

After archiving, deleting, moving or reporting spam, the next conversation
opens: the one below, or the one above at the end of the list. To go back
to the list instead, pick **Go back to the list** under **Settings →
Preferences → After archiving or deleting** (kept per browser).

## In the composer

| Key | What it does |
| --- | --- |
| `Ctrl` + `Enter` (`Cmd` + `Enter`) | Send |
| `Esc` | Close, keeping the draft |
